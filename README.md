# Novus Client

Client Fabric 1.20.1 pour Novus.

## V1 — Novus Title Screen
- Écran titre Novus personnalisé
- Thème orange et blanc
- Boutons Jouer, Solo, Serveur, Options et Quitter
- Base prête pour les futures interfaces directement dans Minecraft

## Architecture prévue
- `novus-ui`: composants d'interface
- `novus-title`: écran principal
- `novus-hud`: HUD personnalisé
- `novus-menu`: menus Novus
